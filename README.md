## Psychedelic deep learning project ##

This project uses an open-access LSD-Placebo fMRI dataset from Openneuro : https://openneuro.org/datasets/ds003059/versions/1.0.0

The main goal is learn how to use deep learning with fMRI data and answer the following questions :
1. Can a deep learning model reliably classify fMRI time series as belonging to an LSD or placebo condition, and with what accuracy and robustness across subjects?
2. Does LSD alter functional connectivity patterns between brain regions compared to placebo, and can these changes be quantified and visualized?
3. Can we identify brain networks that show reduced synchrony or altered temporal coordination under LSD compared to placebo, using deep learning‑based representations of fMRI time series?
